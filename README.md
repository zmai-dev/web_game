# Kids Math Games 🎮

一个面向儿童的趣味数学游戏集合，所有游戏均可直接在浏览器中运行，平板和手机友好。

## 游戏列表

| 游戏 | 说明 |
|------|------|
| [五宫格 T 字谜题](./cube5/) | 在 T 形五宫格中，根据已有色块推理出剩余格子的颜色，锻炼逻辑推理能力 |

## 如何使用

直接在浏览器中打开各游戏目录下的 `index.html` 即可游玩。推荐使用 Chrome、Safari 或 Edge 浏览器。

也可部署到任意静态托管服务（Vercel、Netlify、GitHub Pages 等）。

## 本地开发

```bash
# 克隆仓库
git clone <repo-url>
cd web_game

# 直接用浏览器打开对应游戏的 index.html 即可
# 无需构建步骤
```
