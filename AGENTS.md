# Kids Math Games — AGENTS.md

## Structure

- `/index.html` — game hub page with card links to each game
- `/cube5/` — first game: 五宫格 T 字谜题
  - `index.html` — game layout with grid + sidebar
  - `styles.css` — game styles
  - `app.js` — all game logic (no framework)
  - `index.php` — PHP fallback for PHP-only hosts (cache-bust via `filemtime`)
  - `vercel.json` — SPA rewrite for Vercel deployment
  - `404.html` — auto-generated by panel, ignore

## No build step

Pure static HTML/CSS/JS. Open any `index.html` in a browser to develop.

## Adding a new game

1. Create a new directory (e.g. `/game2/`) with `index.html`, `styles.css`, `app.js`
2. Add a card link in `/index.html` pointing to `./game2/`
3. Add a row in `README.md` game list table

## Fullscreen centering quirk

If the game uses fullscreen API, the fullscreen CSS must use `height: 100vh` (not `min-height`) and add `.app:fullscreen .workspace { justify-content: center; }` for horizontal centering. `min-height: 100vh` breaks `justify-content: center`.

## PHP deployment note

`index.php` mirrors `index.html` with `filemtime` cache-busting on CSS/JS. Keep it in sync when updating `index.html`.
